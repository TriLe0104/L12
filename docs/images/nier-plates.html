03A Reduce

余剰 > 20%

Idle racks with more than 20% slack drop toward consumed / 0.88. Freed watts return to the hall pool. Never below GPU AllowableMin.

03B Hold

5–20% 余白

Operating band. No PATCH. Observed SetPoint is truth — if nvidia-smi set a lower cap, we do not fight it.

→
03C Increase

不足 < 5%

At-cap racks take from the hall pool up to max kW / rack (135), not merely stay-under (108). Hall average stays at 80%.
